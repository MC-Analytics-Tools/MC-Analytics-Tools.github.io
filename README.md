## 📌 About the Project

A collection of advanced performance analysis and telemetry tools for Minecraft. Each tool provides real-time tracking, visual overlays, and gameplay improvement features.

---

## 🔧 Available Tools

- **WURST** — Popular and beginner-friendly performance analyzer with reliable aimbot, clear ESP, and extensive utility and griefing modules.
- **METEOR CLIENT** — Modern and lightweight performance analyzer with strong aimbot, detailed ESP, extensive movement modules, and scripting support.
- **LIQUIDBOUNCE** — Popular open-source performance analyzer with powerful aimbot, detailed ESP, fluid movement modules, and customizable scripts.
